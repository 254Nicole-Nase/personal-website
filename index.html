What I shipped

  • Churn-prediction pipelines. Built the pipeline jobs behind a customer-churn survival model (Random Survival Forest) for M-PESA, Kenya's mobile-money service: feature extraction over six-month histories, dataset merging and scoring, in Python, SQL and Spark, orchestrated with MLRun.
  • Data you can trust. Added checks before every scoring run: schema and feature-order validation, missing values, and row counts reconciled between source and output.
  • A silent data bug. Traced customers disappearing between two databases to phone numbers stored in different formats, and fixed it by standardising the join key.

Took over and owned the deployment of an early-warning model for a phone-financing product and a RAG assistant for an internal security team: fixed their Jenkins and SonarQube builds on a security-hardened base image, deployed them on the ML platform, and set up test access through AWS API Gateway.
  • Shared LLM gateway. Worked on an internal gateway (LiteLLM, FastAPI) that gives teams shared access to language models: an early version with Docker Compose on EC2, then the AWS ECS Fargate build with CI/CD from DEV to UAT.
